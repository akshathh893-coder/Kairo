# Kairo

A suite of offline educational tools for medical exam preparation.

## DAMS Universal Extractor

Load any DAMS HTML quiz file completely offline and convert it into a universal quiz format — regardless of DAMS version (Bootcamp, DVT, T&D, BTR, RR, GT, PYQ and future builds).

See [`dams-universal/README.md`](dams-universal/README.md) for full documentation.
